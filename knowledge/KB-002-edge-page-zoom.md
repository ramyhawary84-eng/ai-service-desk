# KB-002 – Reset accidental page zoom in Microsoft Edge

**Article ID:** KB-002  
**Category:** Software / Applications  
**Knowledge approval:** Approved  
**Automatic response allowed:** Yes  
**Purpose:** Low-risk self-service guidance for the final-project demo.

## When this article applies

An employee using Microsoft Edge on Windows reports that a webpage became unusually large or small after accidentally changing its zoom and wants to restore the default page zoom.

This article does not cover Windows-wide display scaling, unreadable content across multiple applications, or a zoom setting intentionally chosen for accessibility.

## Approved guidance

1. Select the affected Microsoft Edge tab.
2. Press **Ctrl + 0** together, using the number zero. This resets the page zoom.
3. Check whether the page is now displayed at the intended size.

## If the issue continues

If resetting the zoom does not help, or the problem affects other applications, request technician assistance. Explain which applications are affected and what happened after the reset.

Do not change Windows display settings, install software or modify security settings using this article.

## Confirm the outcome

Ask the employee whether the page is now usable. Providing these instructions does not establish that the issue is resolved.
